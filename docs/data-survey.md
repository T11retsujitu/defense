# 一次データ調査結果 (Phase 2)

調査日: 2026-08-15

## 結論

**防衛装備庁の中央調達契約データは、機械的・継続的に取得・正規化可能。**
ただし取得可能なのは令和5年度(2023)以降で、HTMLページの機械取得には制約がある(後述)。
想定していたサイト(企業・年度・カテゴリ横断の検索・集計)は、この一次データで成立する。

## 確認できたデータソース

### 採用: 防衛装備庁「契約に係る情報の公表（中央調達分）」

- 掲載ページ: https://www.mod.go.jp/atla/souhon/supply/jisseki/rakusatu/index.html
- e-Govデータポータル登録: https://data.e-gov.go.jp/data/dataset/mod_20151130_0128
- 根拠: 「公共調達の適正化について」(平成18年8月25日付 財計第2017号)
- 形式: **xlsx** (月次、契約方式別に1ファイル)
- ファイルURL規則 (実ファイルで確認済み):
  - 令和5〜6年度: `.../rakusatu/kohyo_r{YY}/{YY}_{kyoso|zuikei}_kijunijo-{MM}.xlsx`
  - 令和7年度以降: `.../rakusatu/kohyo_r{YY}/{YY}_{kyoso|zuikei}-{MM}.xlsx`
    (令和7年4月1日の予決令改正による公表基準変更でファイル名から「基準以上」が消えた)
  - `YY`=令和年2桁, `MM`=暦月2桁, kyoso=競争入札 / zuikei=随意契約
- 更新頻度: 月次
- 1ファイルあたり契約件数: 22〜516行 (サンプル14ファイルの実測)

## アクセス上の制約 (重要)

- mod.go.jp は Cloudflare 配下。**HTMLページ(index等)へのデータセンターIPからの
  機械アクセスはJSチャレンジで403になる**(実測)。ブラウザからの閲覧は問題ない。
- 一方、**xlsx/pdf等のファイル直接ダウンロードはチャレンジ対象外**で、通常のHTTP
  クライアントで取得できる(実測: 全14ファイル成功)。
- 幸いファイルURLは規則的なため、インデックスHTMLに依存せず
  **年度・月・方式からURLを構成 → 404は「未公表」として扱う**方式で運用可能。
- robots.txt (www.mod.go.jp): `Disallow: /a/`, `/sp/j/` のみ。`/atla/` は対象外。
- 本PoCの取得はリクエスト間隔3秒・キャッシュ必須・再取得なしで実装。

## 判明したリスク・注意点

1. **HTML機械取得不可** — URL規則が変わった場合の追随は手動確認が必要になる
   (現状は規則が安定しており、404検知で異常に気づける)。
2. **過去年度の遡及に限界** — 令和4年度以前は公式サイトから削除済み。
3. **FMS契約の扱い** — 金額最大級の契約相手方が「米空軍省」等の外国政府。
   企業ランキングにそのまま混ぜると誤解を招くため、entity_typeで区別する。
4. **契約金額≠売上高** — 複数年度契約(国庫債務負担行為)は締結年度に全額計上される。
   表示上の明確な注意書きが必須(実装済み)。
5. **部分収録の年度合計** — 全月を取り込むまで年度合計は過小。UIに常時注記が必要(実装済み)。
6. **地方調達は含まれない** — 「防衛省の調達全体」を名乗ることはできない。
   サイト上は「中央調達」と明示する。
7. **公表基準の変更(令和7年4月)** — 公表対象範囲が年度によって異なるため、
   厳密な年度間比較には注意書きが必要。
