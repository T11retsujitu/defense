# 地方調達データの調査と収録方針 (地方調達PoC)

調査日: 2026-08-15

## 背景: 防衛調達全体に占める位置

防衛省の調達改善計画による公式集計(財計第2017号ベース、少額随意契約を除く):

| | 件数 | 金額 | 備考 |
|---|---|---|---|
| 中央調達(防衛装備庁) | 7,455件 | 約5.57兆円(67%) | 本DBで全量収録済み |
| 地方調達 | 約47,000件 | 約2.79兆円(33%) | 全国400超の会計機関で実施 |
| 省全体(令和5年度) | 54,593件 | 約8.37兆円 | |

- 出典: [令和7年度防衛省調達改善計画](https://www.mod.go.jp/j/policy/hyouka/kaigi/pdf/r07_keikaku.pdf)、
  [令和5年度防衛省調達改善計画](https://www.mod.go.jp/j/policy/hyouka/kaigi/pdf/r05_keikaku.pdf)(令和3年度は中央調達55%)
- 中央調達額は防衛力整備計画により令和4年度1.72兆→令和5年度5.57兆へ拡大し、金額シェアが上昇した
  (装備品の大型契約は中央調達に集中するため)。
- 地方調達の内訳は公共工事等 約0.9兆円 + 物品役務等 約1.9兆円で、装備品ではなく
  基地・駐屯地の運営契約(工事・電力・食料・役務等)が中心。

## 収録第1号: 北関東防衛局 (物品・役務)

### ファイル体系 (実ファイルで確認済み)

- 掲載ページ: `https://www.mod.go.jp/rdb/n-kanto/nyusatsu-keiyaku/nyusatukekkasonota/nyusatukekkasonota.html`
- ファイルURL: `https://www.mod.go.jp/rdb/n-kanto/nyusatsu-keiyaku/tyoutatu/kekka/{series}-{YY}{MM}.pdf`
  - `n-b` = 競争入札・物品役務 / `z-b` = 随意契約・物品役務(該当契約がない月はファイルなし)
  - `n-k` / `z-k` = 工事系(未収録。様式が異なるため別途検討)
  - `YY` = 元号年(平成28年=28 … 令和7年=07)、`MM` = 暦月。**年度ではなく暦年月**
  - 命名例外あり(例: `n-b-0604-2.pdf`)。`etl/sources.py` の `NKANTO_IRREGULAR` で管理
- **月次系列は平成28年(2016)まで遡って存在する**(中央調達の令和5年〜より深い)。
  本PoCでは中央調達と揃えて令和5年度以降を収録対象とする。

### 形式

- 電子生成PDF(スキャンではない)、罫線付き表。pdfplumberのデフォルト表抽出で
  ページ跨ぎの行分割なしに取得できることをサンプルで確認(競争93行+23行/月規模)
- 様式は財計第2017号の付紙様式第3(競争入札)/第4(随意契約)で、
  中央調達xlsxと同じ列構成 + 公益法人関連列。**法人番号あり** → 既存の名寄せ資産が使える
- 中央調達との差異:
  - 契約締結日が和暦文字列(`令和7年4月1日`) — 既存 `parse_date` で対応
  - 金額が `104,748,456円` 形式 — 既存 `parse_amount` で対応
  - 見出し文言の微差(「契約締結日」→「契約を締結した日」等) — 見出しの空白除去+部分一致で吸収
  - 数量・単位の独立列がない(件名に含む)
  - **相手方非公表の行がある**(米軍施設の土地所有者等。セルに情報公開法の条文が入る)
    → 架空の企業を登録せず `company_withheld` フラグで収録

## URL発見の方法 (HTMLが403の問題への対処)

mod.go.jpのHTMLページはbot対策によりデータセンターIPから403になる(ファイル本体は直接取得可能)。
ファイル一覧の発見には**国立国会図書館WARP**(インターネット資料収集保存事業)を使う:

- WARPは `https://warp.ndl.go.jp/web/{YYYYMMDDhhmmss}/{URL}` のwayback型URLに対応し、
  mod.go.jp全体を月次でクロールしている(防衛省のサイトID: waid/4686)
- アーカイブされたインデックスHTMLからファイルURLを抽出し、
  ファイル本体は必ず公表元(mod.go.jp)から直接取得する
- 新規月はファイル名の命名規則から構成してプローブする(404はTTL付きマーカーで管理、既存機構)

## 横展開の見通しと限界

- 同型の財計第2017号様式PDFは他の地方防衛局・各自衛隊の調達機関にも展開されている
  (例: 南関東防衛局は別のディレクトリ構成、海自は函館〜鹿屋の多数の契約機関、空自は28会計機関)。
  パーサは共通化できるが、**URL体系・ページ構成の調査は機関ごとに必要**
- 地方調達は全国400超の会計機関に分散しており、全量収録は現実的でない。
  金額の大きい機関から順に追加し、「防衛省公表調達額に対するカバー率」で進捗を測る方針
- 地方調達には基地運営の一般契約(食料・清掃・警備等)が多く、装備契約と単純合算すると
  「防衛産業」の像が歪む → `scope`軸(市場区分)で区別する(methodology参照)
