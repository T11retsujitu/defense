方法論

データ取得方法

防衛装備庁が「契約に係る情報の公表（中央調達分）」として公表するExcelファイル(月次・契約方式別)を取得しています。 取得は低頻度(リクエスト間隔3秒以上)で行い、取得済みファイルはローカルに保存します。 未公表月(404)は確認日時付きで記録し、進行中年度は数日で、過去年度は約90日で再確認します。 取得済みファイルも約30日間隔でETag/Last-Modifiedによる条件付き再取得を行い、公表元の訂正・差し替えを検知します。 差し替えで消えた行はデータベースからも削除します(ゴースト行を残しません)。 ファイルはSHA-256で同一性を管理し、全レコードが取得元ファイルまで追跡できます。

対象となる調達範囲

現在の収録対象は防衛装備庁の中央調達(装備品等の本庁一括調達)のみです。以下は含まれません。

  • 各自衛隊・地方防衛局等による地方調達
  • 公表基準未満の契約(令和6年度以前は「基準以上」のみが公表対象)
  • 秘密保全等の理由で非公表の契約
  • 防衛省本省(内部部局・各機関)・防衛装備庁本部の一般調達

したがって、本サイトの集計は日本の防衛調達全体ではなく、公表された中央調達分の部分集合です。

契約相手方の区分と法人名の正規化

公表ファイルに含まれる法人番号(13桁)を第一の同定キーとし、同一法人番号の契約を同一企業に集約します。 法人番号のない相手方は、辞書(米軍各省等のFMS相手方)・ルール(「米〜省/庁/局」)・住所と名称による区分推定で処理します。 同じ表記が複数の法人番号に対応する場合(同名別法人)は自動解決せず「未解決」とします。 文字列類似だけで別法人を統合することはありません。

契約相手方は次の区分(entity_type)を持ちます: 民間企業(国内) / 外国企業 / 外国政府等(FMS=対外有償軍事援助) / 公的機関 / 区分不明。 「企業ランキング」は民間企業(国内・外国)のみを対象とし、外国政府・公的機関は「契約相手方ランキング」に分離しています。

カテゴリ分類(二軸)

「何を調達したか」と「何のための契約か」は独立した情報であるため、次の二軸で別々に分類します。

  • 装備分野(domain): 航空機 / 艦船 / 陸上装備 / 誘導弾・ミサイル / 弾薬・火器 / 無人機 / 宇宙 / C4ISR・電子機器 / IT・ソフトウェア / 共通・その他 / 未分類
  • 契約目的(nature): 物品取得・その他(既定値) / 研究開発 / 改修・能力向上 / 調査・検討 / 維持整備・修理 / 役務・サービス / 燃料・消耗品 / 産業基盤

例: 「極超音速誘導弾等の生産準備役務」は 装備分野=誘導弾・ミサイル、契約目的=役務・サービス。 「軽油2号(艦船用)」は 装備分野=艦船、契約目的=燃料・消耗品。

分類は契約件名に対するキーワードルール(各軸内で順序付き・決定的)で行い、LLM等の非決定的な手法は使用していません。 装備分野がルールに一致しない契約は未分類のまま保持します。 契約目的が一致しない場合は既定値「物品取得・その他」を適用します。 「物品取得・その他」は分類結果ではなく既定値(仮定)であり、 nature_rule_matched=0 として記録・区別しています。

rule_matched はルールに一致したかどうかのブール値であり、分類が正しい確率(確信度)ではありません。 キーワード分類には誤分類が含まれ得ます。各契約詳細ページで分類根拠の区分を確認できます。

装備分野が未分類の契約には理由コードを付与しています: insufficient_context(FMS・装備認定試験・特定取組など件名だけでは分野を特定できない) / cross_domain(風洞・試験装置など分野横断) / manual_review_pending(未レビュー。ルール追加で解消できる可能性があるもの)。 改善対象は manual_review_pending のみとし、無理な分類で精度を落とさない方針です。

契約額の扱い

  • 金額は公表ファイルの「契約金額」欄の値(円)です。
  • 契約金額は企業の防衛関連売上高ではありません。納期・検収・収益認識の時期は契約締結日と一致しません。
  • 複数年度にわたる契約(国庫債務負担行為)も契約締結年度に全額を計上しています。
  • 変更契約・契約解除による増減は現時点で追跡していません。
  • 年度は契約締結日から導出しています(4月開始の日本の会計年度)。

年度比較の方法

デフォルトで表示する年度は「全12か月分の公表ファイルを収録済みの最新年度」です。 進行中(部分収録)の年度は収録期間(例: 4〜6月累計)を明示し、 前年比較は前年度の同じ期間(前年同期)との比較で計算します。 部分収録年度の合計を通年の年度合計と比較することはしません。

重複疑いレコード

同一公表ファイル内に全項目が完全一致する行が複数存在する場合があります。 公表元が同条件の別契約を複数掲載した可能性と、誤って重複掲載した可能性の両方があるため、 自動削除はせずsuspected_duplicateフラグを付けて収録し、件数・金額を下表で公開しています。 集計値には重複疑い行を含みます。

データ更新頻度

公表元は月次で更新されます。本PoCでは手動実行の取込コマンドで更新します(自動定期実行は未実装)。

当サイトによる加工箇所

  • 金額・日付の型変換(和暦→西暦を含む)
  • 法人名の表記正規化と法人番号による集約、契約相手方区分の付与
  • 装備分野・契約目的の二軸機械分類
  • 契約方式のファイル区分(競争入札/随意契約)からの補完
  • 年度の契約締結日からの導出
  • 契約担当官欄からの部局・所在地の抽出(氏名は保存しません)

公表ファイルの原文は加工と分離して全列保持しており、各契約詳細ページで確認できます。

免責事項

本サイトは政府公表資料を機械的に加工した二次情報であり、正確性・完全性を保証しません。 投資判断・取引の根拠には公表元の一次資料を必ず確認してください。 本サイトは防衛省・防衛装備庁とは無関係であり、掲載内容は公的見解ではありません。
